
# Storage Management (Java - Console)

Small console application for managing a product warehouse.


## Features

- ➕ Adding a product (AddProduct)
- 🗑️ Delete a product (DeleteProduct)
- 📋 Print all products avaible (PrintProducts)
- 🧮 Management of quantity and prices
